Privacy Policy for Clips Uploader

Last updated: October 17, 2026

Clips Uploader is a private tool used only by its owner to upload videos to the owner's own YouTube channel through the YouTube Data API.

What it accesses

With the owner's permission, granted through Google's sign-in screen, it uses YouTube API scopes to upload videos, set their thumbnails, and read the owner's channel's basic information. It does not access any other user's data.

What it stores

Only the sign-in token Google issues, saved on the owner's own computer. No data is collected from anyone else, and no data is sold, shared, or sent anywhere except to YouTube itself.

Revoking access and deleting data

Access can be removed at any time at https://myaccount.google.com/permissions. The only stored data, the sign-in token on the owner's computer, is deleted when access is revoked or the tool is removed, and in any case within 30 days of a deletion request. The tool keeps no copies of YouTube data.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Contact

Questions about this policy can be raised through the GitHub repository that hosts this site.
